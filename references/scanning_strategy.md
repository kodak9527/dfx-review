# DFX 扫描策略与置信度指南

本文件详细说明了 DFX 审视过程中的预检逻辑、文件优先级划分、扫描置信度评级以及异常边界处理。

## 1. 环境预检 (Phase 0)

在开始大规模扫描前，必须验证：
1. **构建文件**：Glob 查找 `**/pom.xml` 或 `**/build.gradle*`。若无，提示非 Java 项目并中止。
2. **多模块检测**：检查 `pom.xml` 是否含 `<modules>` 或 `settings.gradle` 是否含 `include`。
3. **源码目录**：验证 `src/main/java` 是否存在。
4. **Spring Boot 识别**：查找 `@SpringBootApplication` 标注类。

## 2. 文件扫描优先级 (File Priority Groups)

为节省 Token，按以下优先级分批读取分析：

| 优先级 | 文件类型 | Glob 模式 | 说明 |
|--------|---------|----------|------|
| **P0 必读** | Service/Controller/Config | `**/*Service*.java`, `**/*Controller*.java`, `**/*Config*.java` | DFX 信号最密集 |
| **P0 必读** | 切面与拦截器 | `**/aspect/**`, `**/interceptor/**`, `**/filter/**`, `**/listener/**` | 处理横切关注点 |
| **P0 必读** | 配置文件 | `**/application*.yml`, `**/logback*.xml`, `pom.xml` | 配置层 DFX |
| **P1 选读** | 数据访问层 | `**/*Repository*.java`, `**/*Mapper*.java` | 异常/超时/缓存 |
| **P1 选读** | 异步/消息处理 | `**/*Handler*.java`, `**/*Consumer*.java`, `**/*Producer*.java` | 异步逻辑 |
| **P2 可跳过** | 纯数据对象 | `**/entity/**`, `**/dto/**`, `**/enums/**`, `**/model/**` | 信号极少 |
| **P2 可跳过** | 测试代码 | `**/*Test*.java` | 不纳入审视范围 |

## 3. 扫描置信度评级 (Confidence Rating)

| 置信度 | 达成条件 | 影响 |
|--------|---------|------|
| **高** | 已读文件 ≥50%，P0 全覆盖，关键类（Service/Controller）全读 | 评分如实呈现 |
| **中** | 已读文件 30-50%，或 P0 有遗漏 | 最终评分 × 0.9 |
| **低** | 已读文件 <30%，或仅读取了数据对象/DTO | 最终评分 × 0.7，报告标注“采样不足” |

## 4. 阶段二检查点 (Phase 2 Checkpoints)

| 检查点 | 验证条件 | 失败动作 |
|--------|---------|--------|
| 清单非空 | 发现 ≥1 个 .java 文件 | 报告“服务无源码”，跳过该服务 |
| 批量合理 | 每批 P0 ≤ 8 个，P1 ≤ 15 个 | 调整批次大小，防止 Token 溢出 |
| 覆盖率 | 已读文件 < 30% | 发出“覆盖率不足”警告 |

## 5. 边界情况处理 (Edge Cases)

| 场景 | 处理动作 |
|------|----------|
| **单服务项目** | 退化为单服务视图，隐藏跨服务对比区 |
| **巨型服务 (>2000 文件)** | 强制跳过所有 P2，仅精读 P0 核心文件 |
| **非 Spring 项目** | 标注“非 Spring”，仅基于 Java 通用实践评分 |
| **多仓库微服务** | 支持 glob 模式（如 `../*/pom.xml`）扫描同级目录 |
| **文件编码异常** | 优先 UTF-8，失败尝试 GBK，仍失败则跳过 |
